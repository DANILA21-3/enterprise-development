# Разработка корпоративных приложений

## Лабораторная работа №1

Вариант 60: Предметная область — гостиница

## Используемые технологии

- C#
- .NET 10
- xUnit v3
- LINQ
- Microsoft Testing Platform (MTP)

## Ход работы

Для выполнения работы созданы два проекта:

- **Hotel.Domain** — доменная библиотека с классами предметной области
- **Hotel.Tests** — тесты на xUnit v3

### Классы предметной области

Для описания сущностей были реализованы следующие классы:
- `Room` — номер: номер комнаты, этаж, наличие балкона, тип.
- `RoomType` — тип номера: категория, площадь, количество кроватей, наличие ванной, цена за сутки.
- `Client` — клиент: ФИО, дата рождения, номер паспорта, гражданство.
- `Booking` — бронь: клиент, номер, дата заселения, количество суток.
  
А также создан файл  `RoomCategory.cs` для перечисления категорий комнат: *Economy*, *Standart*, *Luxe*, *Business*, *President*.
  
### Тестовые данные

Для удобного запуска тестов в `HotelFixture.cs` подготовлен набор данных:

- 10 типов номеров
- 15 номеров
- 10 клиентов
- 20 бронирований

## Unit тесты

Необходимо было реализовать следующие 5 тестов:
- Вывести информацию о всех клиентах, проживавших в номерах указанного типа, упорядочить по ФИО.
- Вывести информацию о номерах, находящихся в текущем бронировании.
- Вывести топ 5 наиболее часто бронируемых номеров.
- Для каждого номера вывести число бронирований.
- Вывести топ 5 клиентов по суммарной стоимости проживания.

Данные тесты реализованы в файле `HotelTests.cs` c использованием LINQ-запросов согласно паттерну AAA с этими наименованиями:
- `FindClientByTypeRoom`
- `RoomBooked`
- `Top5MostFrequentlyBookedRooms`
- `CountBookingsForEachRoom`
- `Top5ClientsByTotalStay`

## Инструкция к запуску

Для запуска тестов необходимо:

1. Установить **.NET SDK 10**

- `dotnet build`
- `dotnet test`
